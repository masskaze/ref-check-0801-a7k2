# 戦国風雲録

スーパーファミコン版『信長の野望・武将風雲録』をモデルにした、ブラウザで遊べる戦国シミュレーションゲームです。
外部ライブラリなし・ビルド不要。ブラウザで開けばすぐ遊べます。

## 遊びはじめる

**A. リポジトリを取ってきて開く**

```bash
git clone https://github.com/masskaze/ref-check-0801-a7k2.git
cd ref-check-0801-a7k2
open nobunaga/index.html          # macOS
xdg-open nobunaga/index.html      # Linux
start nobunaga\index.html         # Windows
```

**B. 1ファイルだけ落として開く**

`nobunaga/dist/sengoku-fuunroku.html`（約240KB）が全部入りの単一ファイルです。
GitHub の Raw から保存してダブルクリックするだけで動きます。

```bash
node nobunaga/build.mjs           # js/css を編集したら作り直す
```

いずれも `file://` のまま動きます。サーバーは要りません。
記録はブラウザの `localStorage` に自動保存されます（別のブラウザ・別の端末とは共有されません）。

## はじめの一手

1. 〈新しく始める〉→ シナリオと大名家を選ぶ。迷ったら **1560年・織田家**（尾張1国・家臣19人、難易度★★★☆☆）
2. 地図で自国をクリック → 右の盤から命令を選ぶ。国ごとに毎季 1〜3 回まで
3. 序盤の型は **商業 → 徴兵 → 訓練**。金がなければ何もできないので、まず商業と開墾で足腰を作る
4. 民忠が 40 を切ると一揆が起きます。下がったら〈施し〉
5. 家臣の忠誠が 60 を切りはじめたら〈褒美〉か〈茶会〉。放っておくと出奔し、敵に調略されます
6. 〈探索〉は当たりの多い命令です。在野武将・茶器・隠し田が見つかります
7. 攻めるのは **敵国の兵の1.5〜2倍**を用意してから。城攻めは守り手が有利です
8. 出陣したら〈委任〉で自動処理もできますが、鉄砲隊を敵騎馬に当てるだけで戦況は変わります

## 概要

| | |
|---|---|
| 舞台 | 全国 59 か国 |
| 武将 | 266 人（生没年・元服・寿命あり） |
| 大名家 | 41 家（1560年）／ 22 家（1582年） |
| シナリオ | 「群雄割拠」1560年・「天下布武」1582年 |
| 勝利条件 | 全国統一。自家が滅べば敗北 |

一年は春夏秋冬の四季。各国は毎季かならず一回（本城は二回、政治85以上の城主がいれば三回）命令を出せます。
プレイヤーが命令を終えると、他の四十家がいっせいに動きます。

## 原作から引き継いだ仕組み

- **国別の金・米** — 収入も兵糧も国ごと。前線へは〈輸送〉で回す必要があります。
- **文化** — 〈文化振興〉で民忠と商いが潤い、文化は隣国へ自然に伝播します。
- **茶の湯** — 茶器を持つ武将は〈茶会〉を催し、同じ国にいる家臣の忠誠を大きく上げられます。茶器は〈探索〉で見つかります（全30種の宝物）。
- **鉄砲と技術** — 〈技術振興〉で鉄砲が安く・強く・射程が伸びます。堺（和泉）・雑賀（紀伊）・国友（近江）は鉄砲鍛冶の地。
- **三すくみの兵種** — 鉄砲は騎馬に強く、騎馬は足軽に強く、足軽は鉄砲に強い。鉄砲隊には鉄砲が、騎馬隊には軍馬が要ります。
- **人は城** — 相性・野望・義理で忠誠が動き、低い武将は出奔し、敵に調略されます。
- **合戦** — 15×11 の戦場を部隊で動く戦術戦。本丸占拠か敵全滅で勝ち。30ターン経つか兵糧が尽きれば寄せ手の負け。
- **計略** — 流言・扇動（一揆）・調略（寝返り）、合戦中の火計・挑発・内応。
- **朝廷工作** — 献金して官位を得ると、民忠・登用・外交が有利になります。

| 分類 | コマンド |

| 内政 | 開墾／治水／商業／施し |
| 軍事 | 徴兵／訓練／城普請／鉄砲購入／軍馬購入／兵糧購入／兵糧売却／移動／輸送／出陣 |
| 文化 | 技術振興／文化振興／茶会 |
| 人事 | 探索／登用／褒美（金・宝物）／城主任命／追放 |
| 外交 | 同盟／援助／同盟破棄／朝廷工作 |
| 計略 | 流言／扇動／調略 |

## 操作

- 地図：ドラッグで移動、ホイールまたは ＋ － で拡大縮小、矢印キーでスクロール
- 国をクリック → 右の盤から命令を選ぶ
- 目標選択中は右クリックまたは Esc で取り消し
- 合戦：部隊をクリック → 青いマスへ移動／赤い敵を攻撃。〈委任〉で自動、〈退却〉で撤兵
- 記録は `localStorage` に自動保存され、タイトルの〈続きから〉で再開できます

## ファイル構成

```
nobunaga/
├── index.html          画面の骨組み
├── build.mjs           単一HTMLへの結合スクリプト
├── dist/               生成物（sengoku-fuunroku.html … 全部入りの1ファイル）
├── css/style.css       スタイル
├── js/
│   ├── data.js         国59・武将266・宝物30・シナリオ2
│   ├── engine.js       状態／季節処理／収入・収穫／寿命・相続／事件
│   ├── commands.js     全コマンドの実装
│   ├── battle.js       合戦（地形生成・戦闘判定・戦闘AI・戦後処理）
│   ├── ai.js           大名AI（内政方針・外交・計略・出陣判断）
│   ├── ui.js           地図・国情報・コマンドの画面
│   ├── battleui.js     合戦画面
│   └── main.js         起動・進行管理・記録
└── test/               自動テスト
```

`js/*.js` は素の `<script>` で順に読み込まれるだけなので、`file://` からそのまま動きます。

## テスト

```bash
node nobunaga/test/engine.test.mjs      # データ検証・コマンド・合戦・20年シミュレーション（45検査）
node nobunaga/test/smoke.mjs            # 画面の起動確認（Playwright）
node nobunaga/test/battle.mjs           # 出陣から合戦・戦後処理まで（Playwright）
node nobunaga/test/play.mjs 武田 10     # 10季ぶん自動プレイして例外を検出（Playwright）
```

Playwright を使うテストはリポジトリのルートから実行してください。
`GAME_URL` を渡すと単一ファイル版も同じテストにかけられます。

```bash
GAME_URL="file://$PWD/nobunaga/dist/sengoku-fuunroku.html" node nobunaga/test/smoke.mjs
```

## 断り書き

武将の能力値・国の初期値は本作独自の設定で、原作の数値ではありません。
