# 食事・血圧の記録

`saltlog/index.html` の 1 ファイルだけで動きます。組み立て作業（ビルド）は要りません。
外部の部品も読み込みません。開けばそのまま使えます。

---

## 1. 使いはじめ

1. ブラウザで `saltlog/index.html` を開きます。
2. 「設定」を開き、Claude の API キーを入れて「保存」を押します。
3. 「今日」に戻り、食べたものを書いて「AI で推定する」を押します。

API キーは、この端末のブラウザの中だけに保存されます。ほかへは送りません。
ただし共用の端末では使わないでください。

### 開き方についての注意

ファイルを直接ダブルクリックして開く方法（`file://`）では、AI の推定が
通信をはねられることがあります。次のどちらかで開いてください。

- GitHub Pages で公開されている `.../saltlog/` の住所を開く
- パソコンで簡易サーバーを立てて `http://localhost:8080/saltlog/` を開く

記録・グラフ・印刷は、どの開き方でも動きます。

---

## 2. 画面

### 今日

その日の塩分の合計を、いちばん上に出します。目標は1日 6g 以内です。
目標を超えた日は朱色になります。

- **食事を記録する** — 区分（朝／昼／夜／間食）を選び、食べたものを書きます。写真も付けられます。
- **当てはまるもの** — 「汁を残した」「半サイズ」などを選ぶと、推定が変わります。ここが精度をいちばん動かします。
- **AI で推定する** — 推定結果が出ます。内容を見てから「この内容で記録する」を押します。
- **手入力で追加** — AI を使わずに、自分で数値を入れます。
- **修正** — 記録したあとでも、塩分・kcal・カリウムを手で直せます。店の表示値があるときは「店の表示値（実測）」に印を付けます。

血圧は、朝と夜を分けて記録します。朝は起床後・服薬前の値だけがくらべられます。
飲酒後に測ったときは「飲酒後」に印を付けます。レポートの朝のグラフからは外れます。

飲まなかった日は「休肝日」を押します。押した日だけをレポートで数えます。

### 週次レポート

7日分をまとめます。「印刷 / PDF」を押すと、そのまま受診に持参できる形で出ます。

- 塩分の棒グラフ（目標 6g の線、超えた日は朱色）
- 朝の血圧の折れ線（収縮期と拡張期、目安 135／85 の点線）
- 服薬メモが変わった期間の帯
- 平均塩分、目標を守れた日数、朝の収縮期の平均、休肝日、平均カリウム
- 日ごとの内訳の表

「グラフを保存」を押すと、2つのグラフを1枚の SVG で書き出します。

### 設定

- API キーとモデル
- 目標の値（塩分、血圧の目安）
- データの持ち出し（JSON でまるごと、CSV で日ごと・食事・血圧）
- データの読み込み（JSON）

---

## 3. データについて

記録はブラウザの保存領域に入ります。端末をまたぎません。
別の端末で使うときは、設定から JSON で書き出し、そちらで読み込みます。

保存領域には限りがあります。いっぱいになると、古い写真から自動で捨てて場所を空けます。
写真を残したくないときは、設定の「写真を保存」を外してください。

**定期的に JSON で書き出して控えを取ってください。** ブラウザの履歴を消すと記録も消えます。

---

## 4. モデルについて

仕様書の指定どおり `claude-sonnet-4-6` を既定にしています。
設定で次にも変えられます。

| モデル | 特徴 |
|---|---|
| `claude-sonnet-4-6` | 仕様書の指定 |
| `claude-sonnet-5` | より新しく、料金が安い |
| `claude-opus-5` | いちばん高性能。料金は高い |

推定には、仕様書 §4 の目安表と法則をそのまま組み込んでいます。
一般の栄養データではなく、こちらを優先させています。

---

## 5. しないこと

このアプリは記録と可視化だけを行います。

- 薬の増減、用量の是非、診断、治療方針には触れません。
- 血圧の評価や、受診の要否を書きません。
- 推定を頼む文にも、この禁止を明記してあります。

出すのは、塩分・カロリー・カリウム・純アルコールの推定値と、
食べ方・選び方の助言だけです。

---

## 6. 用語

| 言葉 | 意味 |
|---|---|
| 塩分 | 食塩相当量（g） |
| 目標 | 1日 6g 以内 |
| 朝の血圧 | 起床後・服薬前に測った値 |
| 休肝日 | 「休肝日」を押した日 |
| 実測 | 店の表示値。推定より優先します |
