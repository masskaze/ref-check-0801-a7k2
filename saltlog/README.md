# 食事・血圧の記録

`saltlog/index.html` の 1 ファイルだけで動きます。組み立て作業（ビルド）は要りません。
外部の部品も読み込みません。開けばそのまま使えます。

---

## 1. 使いはじめ

1. ブラウザで `saltlog/index.html` を開きます。
2. 「今日」で、食べたものを書きます。**その場で塩分が出ます。**
3. 内容を見て「記録する」を押します。

**API キーがなくても、ここまで全部動きます。** 通信もしません。
料理の名前は、アプリの中の辞書と突き合わせています。

写真から推定したいときだけ、「設定」で Claude の API キーを入れてください。
キーはこの端末のブラウザの中だけに保存されます。共用の端末では使わないでください。

### 開き方についての注意

ファイルを直接ダブルクリックして開く方法（`file://`）では、AI の推定が
通信をはねられることがあります。次のどちらかで開いてください。

- 公開された住所 `https://masskaze.github.io/ref-check-0801-a7k2/saltlog/` を開く
- パソコンで簡易サーバーを立てて `http://localhost:8080/saltlog/` を開く

記録・辞書・グラフ・印刷は、どの開き方でも動きます。

### iPhone のホーム画面に置く

1. Safari で上の住所を開きます。
2. 下の共有ボタン（□に↑）を押します。
3. 「ホーム画面に追加」を選びます。
4. 名前は「塩分と血圧」で出ます。「追加」を押します。

アイコンから開くと、Safari の枠が出ない専用の画面になります。

**注意：ホーム画面のアプリと Safari では、記録が別々に保存されます。**
どちらか一方に決めて使ってください。移すときは、設定から JSON で書き出して読み込みます。

## 2. 画面

### 今日

いちばん上に **この7日の帯** を置いています。上の棒が1日の塩分、下の数字が朝の収縮期です。
記録しながら、週の流れが見えます。今日の列は色を変えています。

その下がその日の合計です。目標は1日 6g 以内で、超えた日は朱色になります。

- **食べたもの** — 書くと、打つそばから塩分が出ます。「担々麺と半チャーハン、餃子3個」のように続けて書けます。
- **当てはまるもの** — 「汁を残した」「半サイズ」などを選ぶと、推定が変わります。ここが精度をいちばん動かします。
- **記録する** — 出ている値でそのまま記録します。
- **AI で推定する** — 写真のときと、辞書に無い料理のときに使います。API キーが要ります。
- **修正** — 品目ごとに塩分を直せます。直した値は、その品目の値として覚えます。次からその値が出ます。
- 店の表示値があるときは「店の表示値（実測）」に印を付けます。

血圧は、朝と夜を分けて記録します。朝は起床後・服薬前の値だけがくらべられます。
飲酒後に測ったときは「飲酒後」に印を付けます。レポートの朝のグラフからは外れます。

飲まなかった日は「休肝日」を押します。押した日だけをレポートで数えます。

### 週次レポート

7日分をまとめます。「印刷 / PDF」を押すと、そのまま受診に持参できる形で出ます。

図は1枚です。**塩分と朝の血圧を、同じ横軸で上下にそろえています。**

- 上：塩分の棒（目標 6g の線、超えた日は朱色）
- 下：朝の血圧の折れ線（収縮期と拡張期、目安 135／85 の点線）
- **6g を超えた日は、縦の帯が上下を貫きます。** その日の血圧と並べて読めます
- 服薬メモが変わった期間の帯と、変わった日の区切り線も上下を貫きます
- 平均塩分、目標を守れた日数、朝の収縮期の平均、休肝日、平均カリウム
- 日ごとの内訳の表

「グラフを保存」を押すと、この図を SVG で書き出します。

### 設定

- API キーとモデル
- 目標の値（塩分、血圧の目安）
- データの持ち出し（JSON でまるごと、CSV で日ごと・食事・血圧）
- データの読み込み（JSON）

## 3. 料理の辞書

アプリの中に約100品の辞書を持っています。名前が合えば、その場で数値が入ります。

- **仕様書 §4 の実測**（ラーメン、担々麺、味噌汁、餃子、定食など19品）は、数か月の記録から出た値です。
- **一般の目安**（丼もの、定食、コンビニ食など）は推定です。実際と違うことがあります。

数え方と大きさも読み取ります。

| 書き方 | 読み取る内容 |
|---|---|
| 餃子6個 | 1個あたり × 6 |
| 半チャーハン | 半分 |
| 大盛ラーメン | 1.35倍 |
| ビール2杯 | 純アルコール 40g |
| ﾗｰﾒﾝ／らーめん | ラーメンとして扱う |

### 直すと覚えます

推定が違っていたら、「修正」で直してください。**その品目の値として覚え、次から使います。**
辞書に無い料理も、名前を付けて覚えられます。使うほど自分の食べ方に合っていきます。

覚えた値は書き出し（JSON）に含まれます。端末を変えても引き継げます。

---

## 4. データについて

記録はブラウザの保存領域に入ります。端末をまたぎません。
別の端末で使うときは、設定から JSON で書き出し、そちらで読み込みます。

保存領域には限りがあります。いっぱいになると、古い写真から自動で捨てて場所を空けます。
写真を残したくないときは、設定の「写真を保存」を外してください。

**定期的に JSON で書き出して控えを取ってください。** ブラウザの履歴を消すと記録も消えます。

iPhone では、しばらく開かないと保存領域が整理されることがあります。
ホーム画面のアイコンから開いていれば消えにくくなりますが、控えは取ってください。

---

## 5. モデルについて

AI は、写真から料理を見分けるときと、辞書に無い書き方をされたときにだけ使います。
文字から料理を割り出すだけなら AI は要りません。

既定は `claude-sonnet-5` です。設定で次にも変えられます。

| モデル | 料金（100万トークンあたり 入力／出力） |
|---|---|
| `claude-sonnet-5` | $2 ／ $10 |
| `claude-opus-5` | $5 ／ $25 |
| `claude-sonnet-4-6` | $3 ／ $15 |

仕様書の当初指定は `claude-sonnet-4-6` でした。後継の `claude-sonnet-5` のほうが
新しく、料金も安いため、既定を入れ替えています。

推定には、仕様書 §4 の目安表と法則をそのまま組み込んでいます。
一般の栄養データではなく、こちらを優先させています。

---

## 6. しないこと

このアプリは記録と可視化だけを行います。

- 薬の増減、用量の是非、診断、治療方針には触れません。
- 血圧の評価や、受診の要否を書きません。
- 推定を頼む文にも、この禁止を明記してあります。

出すのは、塩分・カロリー・カリウム・純アルコールの推定値と、
食べ方・選び方の助言だけです。

---

## 7. 画面の方針

仕様書 §9 に沿っています。

- 淡い緑がかった紙色（`#F1F4EE`）に、方眼の薄い罫
- 白いパネル。基準の範囲は帯で示す
- 外れた値だけを朱（`#B8412A`）、良好な値は緑（`#2F6F4E`）
- 拡張期は青（`#2C6FA8`）で系統を分ける
- 数値は明朝。装飾を足さない

印刷では方眼を出しません。インクを使わないためです。

---

## 8. 用語

| 言葉 | 意味 |
|---|---|
| 塩分 | 食塩相当量（g） |
| 目標 | 1日 6g 以内 |
| 朝の血圧 | 起床後・服薬前に測った値 |
| 休肝日 | 「休肝日」を押した日 |
| 実測 | 店の表示値。推定より優先します |
| 辞書 | アプリの中の料理の一覧。通信しません |
| あなたの値 | 手で直して覚えさせた値。辞書より優先します |
